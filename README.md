# Brew & Bloom — Animated Café Landing Page

A premium, responsive café website concept built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop and mobile layouts
- CSS keyframe animations and animated ticker
- Scroll reveal animations with IntersectionObserver
- Mobile navigation and scroll progress indicator
- Reduced-motion accessibility support
- Café story, sample menu, gallery and contact sections

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
- Replace `hello@example.com` with the café's real email.
- Replace the sample phone number, address, hours and menu prices with verified details.
- Replace the Google Maps destination with the real location.
- Images and Google Fonts load from external services and need an internet connection.

This is a portfolio concept, not a claim of work completed for a real café.
